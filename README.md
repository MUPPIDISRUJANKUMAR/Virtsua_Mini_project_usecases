# Virtusa_Pre_Training_Projects

This repository contains three domain-based projects developed as part of pre-training preparation. These projects demonstrate practical implementation of concepts in Java, Python, and SQL.

Core Java: The "QuizMaster" Online Quiz & Assessment System  
Business Case: An educational platform needs a system to conduct quizzes, evaluate users automatically, and provide performance insights. Manual evaluation is time-consuming and inefficient.  

Problem Statement  
Build an Online Quiz System that allows users to take multiple-choice quizzes, evaluates answers automatically, and provides a result summary with performance analysis.  

Student Tasks:  
1. Question Management: Admin can add questions, options, and correct answers.  
2. Quiz Flow: Display questions one by one and accept user responses.  
3. Timer Logic: Implement a timer-based quiz using loops or threads.  
4. Evaluation System: Calculate score based on correct answers.  
5. Result Analysis: Show total score and performance summary.  

Deliverable: A Java program demonstrating OOP concepts, quiz handling, and result evaluation.  


Core Python: The "SmartExpense" Tracker with Insights  
Business Case: Individuals often fail to track daily expenses and cannot identify where their money is being spent, leading to poor financial management.  

Problem Statement  
Develop a Python application that records, categorizes, and analyzes daily expenses, providing insights into spending patterns.  

Student Tasks:  
1. Data Entry: Record expense details such as date, category, amount, and description.  
2. Data Storage: Store data using CSV or JSON files.  
3. Categorization: Classify expenses into categories like Food, Travel, Bills, etc.  
4. Analysis: Calculate monthly expenses and identify highest spending category.  
5. Visualization: Generate a category-wise pie chart using matplotlib.  

Deliverable: A Python script that tracks expenses and generates useful financial insights.  


SQL: The "RetailSales Insights" Data Analyst  
Business Case: An online retail company wants to analyze its sales data to identify trends, improve revenue, and understand customer behavior.  

Problem Statement  
Design a relational database and write SQL queries to analyze sales performance and generate meaningful business insights.  

Student Tasks:  
1. Schema Design: Create tables for Customers, Products, Orders, and Order_Items.  
2. Top Products: Write a query to find top-selling products.  
3. Customer Analysis: Identify the most valuable customers.  
4. Revenue Calculation: Calculate monthly revenue using aggregate functions.  
5. Category Insights: Perform category-wise sales analysis and detect inactive customers.  

Deliverable: A SQL script that creates the database, inserts sample data, and provides analytical queries.
